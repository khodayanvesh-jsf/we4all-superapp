WE4ALL 3.3.0 - Windows desktop setup

IMPORTANT: This ZIP is flattened. package.json and package-lock.json are in the top-level folder.

1. Extract the ZIP completely, for example to C:\\WE4ALL.
2. Open the extracted C:\\WE4ALL folder in Visual Studio Code (File > Open Folder).
3. Open Terminal > New Terminal. Check that the terminal path ends in \\WE4ALL and that `dir package.json` lists package.json.
4. Install dependencies (internet required the first time):
       npm ci
5. Start the local app:
       npm run dev
6. Open the localhost URL printed by Vite (usually http://localhost:5173).

If `npm ci` says package-lock.json is missing, you are in the wrong folder. Run:
       cd C:\\WE4ALL
       dir package.json
       dir package-lock.json
       npm ci

For offline use after a successful install, start `npm run dev` without internet. Local frontend screens and local-only code work; Supabase auth/data, SMS, live payments, maps and Capgo OTA require internet and configured credentials.

Do not create a real .env from secrets in this archive. Copy .env.example to .env.local and fill only the correct Supabase URL and publishable key for local testing. Never put Supabase secret/service-role keys in VITE_ variables or frontend files.
